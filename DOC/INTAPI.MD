# UCDOS 中断参考

每条说明一个软件中断功能。标题中的括号内数字是对应十六进制数的十进制值。调用方按「调用时」装入寄存器并执行该中断，再按「返回」读取结果。

远指针写成段:偏移。`ZF` 是标志字的第 6 位。没有列出的寄存器，调用前后都不作为本功能的接口。

`INT 48H` 只在 SDK 图形驱动驻留期间有效。`AH` 必须为 `90H`，否则该中断立即返回。

## Int 2FH (47)
### Function DB00H (56064) — 检测 UCDOS 是否驻留

判断 UCDOS 多路中断处理程序是否已经安装。

**调用时：**

- `AX = DB00H`

**返回：**

- `BX = 5450H`：UCDOS 已驻留。`5450H` 即字符 `TP`
- `BX` 为其他值：UCDOS 未驻留

**说明：**

- 本功能不使用进位标志表示成败。
- 查询具体模块之前应先调用本功能。

**示例：**

```asm
        mov     ax,0db00h           ;功能号
        int     2fh                 ;检测 UCDOS
        cmp     bx,5450h            ;签名 TP
        jne     not_resident
```

## Int 79H (121)
### Function 00H (0) — 检测模块是否驻留

判断一个 UCDOS 常驻模块是否已经安装。

**调用时：**

- `AH = 00H`
- `AL = 模块号`
  - `00H`：`RD16`，16×16 显示字库
  - `01H`：`RDPS` 或 `RDFNT`，轮廓字库

**返回：**

- `ZF` 置位：该模块已驻留
- `ZF` 清位：该模块未驻留

**说明：**

- 调用前应先确认 UCDOS 本身已驻留，即 `INT 2FH` 功能 `DB00H` 返回 `BX = 5450H`。
- 其他模块号的含义未定义。

**示例：**

```asm
        mov     ah,0                ;功能号
        mov     al,0                ;模块 0 = RD16
        int     79h
        jz      rd16_present        ;ZF 置位表示已驻留
```

## Int 7FH (127)
### 读取 16×16 显示点阵

按字符编码读取一幅 16×16 显示点阵。

**调用时：**

- `DH = 字符第一字节`
- `DL = 字符第二字节`

**返回：**

- `DX = 点阵所在段`
- 点阵偏移固定为 0，长度为 32 字节

**说明：**

- 返回后 `DX` 不再保存字符编码。
- 点阵共 16 行，每行 2 字节。每个字节的位 7 是该行最左边的像素。
- 使用本功能前，模块 `00H` 必须已经驻留。
- `DX = FFFFH` 不是字符编码，那个入口用来读取启动驱动器。

**示例：**

```asm
        mov     dh,0b0h             ;字符第一字节
        mov     dl,0a1h             ;字符第二字节
        int     7fh
        mov     es,dx               ;点阵在 ES:0000
        xor     di,di
        mov     cx,16               ;复制 32 字节
        rep     movsw
```

## Int 7FH (127)
### DX = FFFFH — 读取启动驱动器

返回 UCDOS 所在驱动器的编号。

**调用时：**

- `DX = FFFFH`

**返回：**

- `DL = 驱动器字母`。`41H` 为 `A`，`42H` 为 `B`，`43H` 为 `C`，依此类推

**说明：**

- 本入口与读取点阵共用 `INT 7FH`。`FFFFH` 选择驱动器查询。
- 返回值是字母本身，不是从 0 起算的驱动器号。可直接写入路径的盘符字节。

**示例：**

```asm
        mov     dx,0ffffh
        int     7fh
        mov     drive,dl            ;保存驱动器编号
```

## Int 7EH (126)
### 读取轮廓字点阵

按指定字号和尺寸，把轮廓字点阵写入调用方缓冲区。

**调用时：**

- `DS:SI = 请求块地址`
- `ES:DI = 点阵缓冲区地址`

请求块按字节连续存放：

| 偏移 | 大小 | 内容 |
| --- | --- | --- |
| 0 | BYTE | 字符第二字节 |
| 1 | BYTE | 字符第一字节 |
| 2 | WORD | 字库号 |
| 4 | WORD | 宽度，单位为像素 |
| 6 | WORD | 高度，单位为像素 |
| 8 | WORD | 起始行。0 表示顶端 |
| 10 | WORD | 结束行。通常为高度减 1 |
| 12 | WORD | 格式。1 表示显示格式 |
| 14 | WORD | 缓冲区容量，单位为字节 |

**返回：**

- 点阵写入 `ES:DI`。每个像素占 1 位，位 7 为该字节最左侧像素，各行依次排列

**说明：**

- 字符两个字节的存放顺序与字符串中的顺序相反。
- 偏移 4 在调用前是请求宽度。返回后可以成为实际字宽；比例字体用这个值作为前进量。
- 偏移 12 的低字节为 1，表示显示格式。需要等宽字形时再把位 6 置 1，于是该字为 `0001H` 或 `0041H`。
- 容量通常取 `((宽度 + 7) / 8 × 高度) × 2 + 3072`。缓冲区不得小于该容量，也不应小于 `max(4096, ((宽度 + 7) / 8 × 高度) × 4)`。
- 使用本功能前，模块 `01H` 必须已经驻留。

**示例：**

```asm
        mov     si,offset req       ;请求块
        mov     di,offset dots      ;点阵缓冲区
        push    ds
        pop     es
        int     7eh
```

## Int 10H (16)
### Function 00H (0) — 设置显示模式

选择当前显示模式。

**调用时：**

- `AH = 00H`
- `AL = 模式`

| 模式 | 含义 |
| --- | --- |
| `03H` | 文本模式 |
| `08H` | 800×600，16 色 |
| `09H` | 1024×768，16 色 |
| `0AH` | 640×480，256 色 |
| `0BH` | 800×600，256 色 |
| `0CH` | 1024×768，256 色 |
| `12H` | 标准 VGA 图形模式。启用图形光标前使用 |

**返回：**

- 无

**说明：**

- 本功能沿用 BIOS 的模式设置编号，并增加上表中的扩展图形模式。

**示例：**

```asm
        mov     ah,0                ;功能号
        mov     al,03h              ;80×25 文本
        int     10h
```

## Int 10H (16)
### Function 09H (9) — 写字符及属性

在当前光标处写入一个字节及其显示属性。光标不移动。

**调用时：**

- `AH = 09H`
- `AL = 字节`
- `BH = 00H`，显示页
- `BL = 显示属性`
- `CX = 重复次数`。写汉字时必须为 1

**返回：**

- 无

**说明：**

- 一个汉字分成两次写入。先写低字节，用功能 `02H` 把光标前进一列，再写高字节。
- 调用前用功能 `02H` 定位。

**示例：**

```asm
        mov     ah,02h              ;先定位
        mov     bh,0
        mov     dx,rowcol
        int     10h
        mov     ah,09h
        mov     al,byte ptr han     ;低字节
        mov     bh,0
        mov     bl,0fh              ;属性
        mov     cx,1
        int     10h
```

## Int 10H (16)
### Function 0EH (14) — 电传输出

把一个字节按电传方式输出，并移动光标。

**调用时：**

- `AH = 0EH`
- `AL = 字节`
- `BH = 00H`

**返回：**

- 无

**说明：**

- 输出字符串时，每个字节调用一次，遇到 0 字节停止。

```asm

        mov     bh,0
        int     10h
        jmp     next
```

- 无

**说明：**

- 调用期间 `DS` 改为参数块所在段，`SI` 为其偏移。返回后恢复 `DS`。

**示例：**

```asm
        mov     ax,90fah
        mov     bh,2
        lds     si,arc_ptr
        int     48h
```

## 图形驱动入口

下面的功能调用 `INT 10H` 功能 `9535H` 返回的远地址，不执行 `INT` 指令。参数和返回值仍然用寄存器表示。

## 远调用
### AH = 04H (4)，BH = 01H (1) — 计算行字节数

计算一行图像占用的字节数。

**调用时：**

- `AH = 04H`
- `BH = 01H`
- `CX = 宽度`，单位为像素

**返回：**

- `AX = 一行的字节数`

**说明：**

- 宽度以像素计，返回值以字节计。

**示例：**

```asm
        mov     ah,4
        mov     bh,1
        mov     cx,width
        call    dword ptr entry
        mov     stride,ax
```

---

## 远调用
### AH = 04H (4)，BH = 02H (2) — 读取屏幕块

把屏幕上的一个矩形读入缓冲区。

**调用时：**

- `AH = 04H`
- `BH = 02H`
- `CX, DX = 左上角`
- `SI = 宽度`
- `DI = 高度`
- `ES:BP = 目标缓冲区`

**返回：**

- 无

**说明：**

- 缓冲区长度至少为行字节数乘以高度。行字节数用 `BH = 01H` 取得。

**示例：**

```asm
        mov     ah,4
        mov     bh,2
        mov     cx,x
        mov     dx,y
        mov     si,width
        mov     di,height
        les     bp,buf
        call    dword ptr entry
```

---

## 远调用
### AH = 04H (4)，BH = 03H (3) — 写入屏幕块

把缓冲区中的一个矩形写到屏幕上。寄存器与读取屏幕块相同，`ES:BP` 为源缓冲区，`BH = 03H`。

**调用时：**

- `AH = 04H`
- `BH = 03H`
- `CX, DX = 左上角`
- `SI = 宽度`
- `DI = 高度`
- `ES:BP = 源缓冲区`

**返回：**

- 无

**说明：**

- 寄存器与读取屏幕块相同，`BH = 03H`，`ES:BP` 改为源缓冲区。

**示例：**

```asm
        mov     ah,4
        mov     bh,3
        mov     cx,x
        mov     dx,y
        mov     si,width
        mov     di,height
        les     bp,buf
        call    dword ptr entry
```

---

## 远调用
### AX = 0AFFH (2815) — 提交调色板范围

向驱动提交一段调色板索引。

**调用时：**

- `AX = 0AFFH`
- `BX = 第一个索引`
- `CX = 数量`

**返回：**

- 无

**说明：**

- 起始索引与数量之和大于 256 时，数量截断到剩余项数。

**示例：**

```asm
        mov     ax,0affh
        mov     bx,first
        mov     cx,count
        call    dword ptr entry
```

---

## 远调用
### AH = 0AH (10) — 转换 DIB 行

按参数块转换 DIB 图像行。

**调用时：**

- `AH = 0AH`
- `AL = 每像素位数`
- `CX = 行参数`。逐行转换时传入当前行号
- `ES:BP = 参数块`

参数块按字节对齐：

| 偏移 | 大小 | 内容 |
| --- | --- | --- |
| 0 | 远指针 | 源缓冲区 |
| 4 | 远指针 | 目标缓冲区 |
| 8 | WORD | 宽度 |
| 10 | WORD | 颜色 |
| 12 | 远指针 | 源调色板 |
| 16 | 远指针 | 目标调色板 |
| 20 | BYTE | 保留。现有调用均传入 0 |

**返回：**

- 无

**说明：**

- 位深度由 `AL` 传入，不是参数块中的一项。
- 调用方保存并恢复 `ES` 和 `BP`。

**示例：**

```asm
        push    es
        push    bp
        mov     ah,0ah
        mov     al,bits
        mov     cx,row
        les     bp,packet
        call    dword ptr entry
        pop     bp
        pop     es
```

## 不在本参考中的接口

SDK 还使用下列系统接口。它们不是 UCDOS 功能号，这里不重新定义。

| 调用 | 接口 |
| --- | --- |
| `INT 21H`，`AH = 25H` 或 `AH = 35H` | 设置或读取中断向量 |
| `INT 21H`，`AH = 49H` | 释放内存块 |
| `INT 2FH`，`AX = 4300H` 或 `AX = 4310H` | 扩展内存服务的安装检查和入口 |
| 扩展内存远调用，`AH = 0AH`，`DX = 句柄` | 释放一块扩展内存 |
| `INT 33H` | 鼠标。图形驱动驻留期间会暂时替换这个向量 |
| `INT 08H`、`INT 1CH` | 时钟 |
